Frequently Asked Questions

Need further help? Visit the forum via our contact page: Contact.

What is Ankora Linux 5.0?

A free, systemd-free Turkish distribution built on Devuan 6.0 Excalibur and Linux 6.12 LTS with the AyazDE 5.0 desktop.

Does it work on older laptops?

Yes. It targets ~750 MB idle RAM, automatically enables ZRAM (zstd/lz4) below 4 GB, and boots from 2 GB RAM.

Can I test without wiping my disk?

Yes. Booting the Live USB leaves your existing partitions untouched.

How do I upgrade from 4.7.x to 5.0?

Use Ayaz Updater or install ayaz-de-latest-amd64.deb; 4.6.x users should perform a clean ISO install.

Which keyboard layouts are included?

Turkish interface with Turkish, English, German, French, and UK English keyboard options.

Can Ankora AI run arbitrary shell commands?

No. Only 18 predefined agent actions and 33 fixed commands are allowed with explicit user confirmation.
