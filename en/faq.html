Frequently asked questions

If you cannot find your answer, see the contact page. Contact.

What is Ankora Linux?

It is a simple Turkish operating system for everyday users. It is built on Devuan and comes with its own desktop environment, Ayaz DE.

Does it run on an old computer?

Yes. It uses about 750 MB of memory when idle and runs no unnecessary programs in the background. It runs comfortably on a laptop with 2 GB of memory; very old machines with 1 GB are not recommended.

Can I try it without erasing my disk?

Yes. When you write the ISO to a USB stick and boot it, the system on the disk is not touched.

How do I install it?

Write the ISO to a USB stick and boot the computer from it. The installer guides you step by step. Details are on the download page.

Does it cost anything?

No, it is completely free. The source code is open, so you can study and change it as you wish.

How do updates arrive?

Updates come only from the Ankora repositories. Every package is checked while it downloads, and a broken one will not install.

What is the interface language?

The interface is entirely in Turkish. For the keyboard you can pick Turkish, English, German, French or British (GB).

How can I contribute?

Fork the GitHub repository and send a pull request, or share questions and suggestions on the forum.
