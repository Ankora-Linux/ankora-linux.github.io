Download and Install

Use a clean ISO for new setups or 4.6.x upgrades, the .deb package for 4.7.x systems, or install local Ollama AI.

Open GitHub Releases Browse Source Code

System Requirements

  • 64-bit (amd64) processor with UEFI or legacy BIOS
  • 2 GB RAM minimum live (4 GB recommended daily, 8 GB+ for local Ollama)
  • 16 GB+ disk space and 4 GB+ USB flash drive
  • Open-source Mesa graphics with verified AMD/Intel firmware

Three clear steps

  1. Download Verified Release

    Fetch the ISO image and SHA256SUMS from GitHub Releases.

  2. Flash Safely

    Check SHA-256 sums and write only to a removable USB flash device.

  3. Boot & Install

    Start from USB and follow the guided Turkish installer.

Commands by installation path

# Download ISO and SHA256SUMS from GitHub Releases and verify:
sha256sum -c SHA256SUMS --ignore-missing
lsblk -o NAME,SIZE,TRAN,RM

Required for fresh hardware and upgrades from 4.6.x (Daedalus).

Upgrade Policy

Upgrading from 4.6.x (Daedalus) requires a fresh ISO install due to the Devuan 6 / Tauri 2.0 ABI shift.
