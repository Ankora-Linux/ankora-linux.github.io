Ankora Linux 4.0 features

Ayaz DE 4.0 combines 18 built-in desktop windows, 14 full-system theme bundles, a 278-package software store, and Eco RAM mode on a lightweight WebKitGTK and Rust Tauri core.

At a glance

What stands out in release 4.0

01

Eco RAM mode & ~750 MB idle

Automatically trims background load on machines under 4 GB of RAM and unmounts closed windows from the DOM after 30 seconds.

02

Turkish throughout

The installer, desktop, file manager, AI system assistant, and all settings are written in Turkish.

03

18 built-in windows

Files, browser, Ankora Office, PDF viewer, calculator, USB/ISO flasher, and Start menu editor come preinstalled.

04

278 packages & ETAP support

The Software Store includes everyday apps alongside MEB Certificate, Scratch, GCompris, GeoGebra, and smartboard touch drivers.

05

14 full-system themes

A single click updates window surfaces, the taskbar, wallpaper, icon set, and accent colour together.

06

Ankora AI & one-click updater

Runs local diagnostics via Ollama or cloud API models with one-time security token confirmation, plus passwordless system updates.

Apps

18 built-in tools ready out of the box

You do not have to install separate programs for daily tasks.

  • Web browser (Ayaz & Brave)
  • File Manager with menu bar & automatic USB mounting
  • Document, PDF, and photo viewer
  • Ankora Office & notepad
  • Calculator & screenshot tool
  • USB & ISO flasher and formatter
  • Software Store (278 packages)
  • Ankora AI System Assistant
  • System Settings, Ayaz Updater & Task Manager
