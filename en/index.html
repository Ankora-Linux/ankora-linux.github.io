Bring your old computer back to life

Ankora Linux is a free Turkish operating system. It is light, easy to install, and comes with everything you need for everyday tasks.

Download Features
Why Ankora

Three simple reasons

Light

It uses about 750 MB of memory when idle. There is a comparison table on the home page.

Turkish

From the installer to the desktop, everything is in Turkish. You will not have to look up English terms.

Easy to install

Write it to a USB stick and boot. The wizard guides you step by step, and no terminal is needed.

What is inside

Ready to use from the start

You do not have to install separate programs. The tools for everyday tasks are already there.

  • Web browser
  • File manager
  • Document and photo viewer
  • Notepad and calculator
  • App store
  • One-button updater

Install

Ready in three steps

  1. Download

    Get the ISO file. A verification file sits next to it.

    Start the computer from the USB stick. The wizard explains the rest.

FAQ

Common questions

What is Ankora Linux?

It is a simple Turkish operating system for everyday users. It is built on Devuan and comes with its own desktop environment, Ayaz DE.

Does it run on an old computer?

Yes. It uses about 750 MB of memory when idle. It runs comfortably on a laptop with 2 GB of memory; very old machines with 1 GB are not recommended.

Does it cost anything?

No, it is completely free. The source code is open.

How do I install it?

Write the ISO to a USB stick and boot the computer from it. The installer guides you step by step.
