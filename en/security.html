Ankora Linux 5.0 Security Architecture

148 Rust Tauri IPC commands isolate UI actions from the host. AI commands pass strict allowlists and consume 60-second tokens.

Enforced in compiled Rust

Allowlisted Terminal Execution

Built-in terminal checks 33 exact commands and 26 utilities while blocking 59 sensitive binaries from direct execution.

60-Second One-Time AI Token

The AI agent may propose only 18 predefined actions, requiring manual confirmation and a fresh SHA-256 token.

Least Privilege & Pinned GPG

Package installs, updates, and USB writes require pkexec; vendor GPG keys are verified against pinned fingerprints.

Verifiable source guardrails

  • EXACT_ALLOWED_COMMANDS permits 33 fixed diagnostic commands alongside 26 ALLOWED_UTILITIES.
  • FORBIDDEN_LAUNCH_BINARIES blocks direct launch of 59 network and administrative binaries.
  • ALLOWED_AGENT_ACTIONS restricts the AI agent to 18 actions guarded by 60-second single-use tokens.
  • Document viewer validates 20 safe extensions and denies access to 19 sensitive path patterns such as .vault_secret.
  • 148 Tauri IPC commands and 19 automated Rust unit tests protect the host bridge alongside bwrap WebKit sandboxing.

Found a security issue? Email linuxankora@gmail.com privately rather than filing a public issue (48-hour response target).
