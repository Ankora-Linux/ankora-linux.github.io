Descargar e instalar

Una memoria USB y unos minutos bastan. Si ya usa Linux, puede cambiar con un solo comando.

Abrir las versiones de Ankora Linux 3.0 Código fuente
Requisitos

Lo que necesita

  • Un procesador de 64 bits (amd64)
  • Al menos 2 GB de memoria (4 GB son cómodos)
  • Una memoria USB vacía para la ISO
  • Una conexión a internet (para la descarga)
Instalación

Listo en tres pasos

  1. Descargar

    Obtenga el archivo ISO y su archivo de verificación desde la página de versiones.

  2. Escribir en una memoria USB

    Escriba la ISO en una memoria USB vacía con un programa gratuito como BalenaEtcher o Rufus.

  3. Arrancar e instalar

    Arranque el ordenador desde la memoria USB. El instalador avanza paso a paso y el sistema se reinicia al final.

Línea de comandos

Si prefiere la terminal

gh release download --repo Ankora-Linux/Ankora \
  --pattern '*.iso*'

sha256sum -c *.iso.sha256

lsblk -d -o NAME,SIZE,MODEL
sudo dd if=ankora-linux.iso of=/dev/sdX bs=4M status=progress conv=fsync
Atención

Compruebe usted mismo la ruta /dev/sdX. Si elige la unidad equivocada, se borra su contenido.
