Herunterladen und installieren

Wählen Sie zwischen sauberer ISO-Installation, direktem .deb-Upgrade von 4.7.x oder lokaler KI-Einrichtung.

Ankora Linux 5.0 Releases öffnen Quellcode auf GitHub

Voraussetzungen

  • 64-Bit-Prozessor (amd64), UEFI oder klassisches BIOS
  • Mindestens 2 GB RAM im Live-Betrieb (4 GB empfohlen, 8 GB+ für lokales Ollama)
  • Mindestens 16 GB Speicherplatz für feste Installation und 4-GB-USB-Stick
  • Open-Source Mesa + geprüfte AMD/Intel-Kernel-Firmware

In drei Schritten bereit

  1. Herunterladen

    ISO und SHA256SUMS von GitHub Releases beziehen.

  2. Prüfen & Schreiben

    Prüfsumme mit sha256sum kontrollieren und auf ein reines USB-Gerät schreiben.

  3. Installieren

    Rechner vom USB-Stick booten und dem Installationsassistenten folgen.

Befehle für Terminal und Upgrade

# ISO und SHA256SUMS von GitHub Releases laden und prüfen:
sha256sum -c SHA256SUMS --ignore-missing
lsblk -o NAME,SIZE,TRAN,RM

Für neue Rechner und Upgrades von 4.6.x (Daedalus) erforderlich.

Hinweis zum Upgrade

Von 4.6.x (Daedalus) ist wegen des Wechsels auf Devuan 6 / Tauri 2.0 eine saubere ISO-Installation erforderlich.
