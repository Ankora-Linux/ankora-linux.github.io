Herunterladen und installieren

Ein USB-Stick und ein paar Minuten genügen. Wenn Sie bereits Linux nutzen, können Sie das ISO auch direkt über die Kommandozeile prüfen und schreiben.

Ankora Linux 4.0 Versionen öffnen Quellcode auf GitHub
Voraussetzungen

Was Sie brauchen

  • Einen 64-Bit-Prozessor (amd64)
  • Mindestens 2 GB Arbeitsspeicher (Eco-RAM-Modus aktiv unter 4 GB)
  • Einen leeren USB-Stick (mindestens 4 GB) für die ISO
  • Eine Internetverbindung (für den Download)
Installation

In drei Schritten bereit

  1. Herunterladen

    Holen Sie sich die ISO-Datei und ihre SHA-256-Prüfdatei von der Versionsseite.

  2. Auf einen USB-Stick schreiben

    Schreiben Sie die ISO mit dem Ankora USB-Schreiber, BalenaEtcher oder Rufus auf einen leeren USB-Stick.

  3. Starten und installieren

    Starten Sie den Computer vom USB-Stick. Der Installer läuft Schritt für Schritt und startet das System am Ende neu.

Kommandozeile

Wenn Sie das Terminal bevorzugen

gh release download --repo Ankora-Linux/Ankora \
  --pattern '*.iso*'

sha256sum -c *.iso.sha256

lsblk -d -o NAME,SIZE,MODEL
sudo dd if=ankora-linux.iso of=/dev/sdX bs=4M status=progress conv=fsync
Achtung

Prüfen Sie den Pfad /dev/sdX selbst. Bei der falschen Wahl wird der Inhalt dieses Laufwerks gelöscht.
